1. "no such column" error on startup
   → Run: python migrate_settings_columns.py

2. Settings not saving
   → Check: JWT token validity (should be in Authorization header)

3. Frontend not showing settings
   → Check: SettingsPage.jsx is imported in routing
   → Verify: settingsService.js is correctly implemented

4. API returning 500 error
   → Check: Backend logs for validation errors
   → Verify: Field types match database schema

5. Settings not persisting after refresh
   → Check: Browser localStorage is enabled
   → Verify: loadSettings() is called on mount
