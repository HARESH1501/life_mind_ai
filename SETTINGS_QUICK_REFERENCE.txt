SETTINGS BREAKDOWN
================================================================================

THEME:
  Value: 'light' | 'dark' | 'system'
  Stored: localStorage
  Default: 'dark'
  Action: Reload theme, update colors

ACCENT COLOR:
  Value: 'cyan' | 'purple' | 'blue' | 'green'
  Stored: localStorage
  Default: 'cyan'
  Action: Change primary accent color

SIDEBAR MODE:
  Value: 'expanded' | 'compact'
  Stored: localStorage
  Default: 'expanded'
  Action: Collapse/expand sidebar width

NEON GLOW:
  Value: true | false
  Stored: localStorage
  Default: true
  Action: Toggle cyan border glows

BACKGROUND ANIMATION:
  Value: true | false
  Stored: localStorage
  Default: true
  Action: Toggle animated gradients

EMAIL NOTIFICATIONS:
  Value: true | false
  Stored: localStorage
  Default: true
  Action: Enable/disable email alerts

DAILY SUMMARY:
  Value: true | false
  Stored: localStorage
  Default: true
  Action: Enable/disable daily digest

================================================================================
USING SETTINGS IN YOUR CODE
================================================================================

IMPORT:
import { useSettingsStore } from '../store/settingsStore';

ACCESS:
const { theme, accentColor, neonGlow } = useSettingsStore();

UPDATE:
const { setTheme } = useSettingsStore();
setTheme('light');

LISTEN:
useSettingsStore.subscribe(
  (state) => state.theme,
  (newTheme) => console.log(newTheme)
);

DEBUGGING TIPS
================================================================================

1. CHECK STORAGE:
   DevTools → Application → Storage → localStorage
   Find key: "lifemind-settings"

2. LOG SETTINGS:
   console.log(useSettingsStore.getState());

3. CLEAR SETTINGS:
   localStorage.removeItem('lifemind-settings');
   Then refresh page

4. VERIFY STORE:
   DevTools → Console:
   useSettingsStore.getState()

5. CHECK ERRORS:
   DevTools → Console tab
   Look for red error messages
