## 🔍 If Something Doesn't Work

### Settings drawer not appearing?
1. Make sure sidebar is expanded (not collapsed)
2. Look for "Settings" button at bottom of sidebar
3. Click it - drawer should slide in from right

### Settings not changing?
1. Check browser console (F12) for errors
2. Verify you're clicking on radio buttons/toggles
3. Try clicking again

### Settings not persisting?
1. Refresh page (F5)
2. Open DevTools → Application → Storage → localStorage
3. Look for key: "lifemind-settings"
4. Should see your settings saved

### Drawer sliding wrong way?
1. Drawer should come from RIGHT side
2. It slides from x: 320 to x: 0
3. This is correct behavior
