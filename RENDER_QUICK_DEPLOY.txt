                    RENDER DEPLOYMENT - QUICK STEPS
═══════════════════════════════════════════════════════════════════════

🚀 DEPLOY IN 15 MINUTES

═══════════════════════════════════════════════════════════════════════
                         STEP 1: PUSH TO GITHUB
═══════════════════════════════════════════════════════════════════════

cd d:\LifeMind-AI
git add .
git commit -m "Prepare for Render deployment"
git push origin main

═══════════════════════════════════════════════════════════════════════
                      STEP 2: CREATE POSTGRESQL (3 min)
═══════════════════════════════════════════════════════════════════════

1. Go to: https://dashboard.render.com
2. Click: "New +" → "PostgreSQL"
3. Configure:
   Name: lifemind-db
   Database: lifemind_production
   Plan: Free (or Starter $7/mo)
4. Click: "Create Database"
5. COPY: Internal Database URL → Save it!

═══════════════════════════════════════════════════════════════════════
                      STEP 3: DEPLOY BACKEND (7 min)
═══════════════════════════════════════════════════════════════════════

1. Click: "New +" → "Web Service"
2. Connect: Your GitHub repo
3. Configure:
   Name: lifemind-api
   Root Directory: backend
   Runtime: Python 3
   Build Command: pip install -r requirements.txt
   Start Command: uvicorn main:app --host 0.0.0.0 --port $PORT
   Plan: Free

4. Add Environment Variables:
   ┌─────────────────────────────────────────────────────────────┐
   │ ENVIRONMENT          = production                            │
   │ DATABASE_URL         = <paste-from-step-2>                  │
   │ SECRET_KEY           = <generate-random-32-char-string>     │
   │ ALLOWED_ORIGINS      = https://lifemind-ai.onrender.com    │
   │ SMTP_USER            = your-email@gmail.com                 │
   │ SMTP_PASSWORD        = your-gmail-app-password              │
   │ SMTP_HOST            = smtp.gmail.com                       │
   │ SMTP_PORT            = 587                                  │
   └─────────────────────────────────────────────────────────────┘

5. Click: "Create Web Service"
6. Wait for deployment (5-7 minutes)
7. COPY: Backend URL → Save it!
   Example: https://lifemind-api.onrender.com

═══════════════════════════════════════════════════════════════════════
                      STEP 4: DEPLOY FRONTEND (5 min)
═══════════════════════════════════════════════════════════════════════

1. Click: "New +" → "Static Site"
2. Connect: Your GitHub repo
3. Configure:
   Name: lifemind-ai
   Root Directory: frontend
   Build Command: npm run build
   Publish Directory: dist

4. Add Environment Variable:
   ┌─────────────────────────────────────────────────────────────┐
   │ VITE_API_URL = https://lifemind-api.onrender.com           │
   │                ↑ Use your backend URL from Step 3!          │
   └─────────────────────────────────────────────────────────────┘

5. Click: "Create Static Site"
6. Wait for build (3-5 minutes)
7. YOUR APP IS LIVE! 🎉

═══════════════════════════════════════════════════════════════════════
                      STEP 5: UPDATE BACKEND CORS
═══════════════════════════════════════════════════════════════════════

1. Go to: Backend service (lifemind-api)
2. Click: "Environment"
3. Edit: ALLOWED_ORIGINS
4. Set to: https://lifemind-ai.onrender.com
5. Click: "Save Changes"
6. Backend will auto-redeploy
