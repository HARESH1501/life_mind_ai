================================================================================
                           QUICK START
================================================================================

PREREQUISITES:
✓ Python 3.8+
✓ Node.js 16+
✓ pip and npm
✓ Git

START BACKEND:
1. Open terminal
2. cd backend
3. pip install -r requirements.txt (if needed)
4. python main.py
5. Visit http://localhost:8000/api/v1

START FRONTEND:
1. Open new terminal
2. cd frontend
3. npm install (if needed)
4. npm run dev
5. Visit http://localhost:5173

ACCESS SETTINGS:
→ http://localhost:5173/settings
